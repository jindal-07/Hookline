# Scriptwriter Skill - Writing Guidelines

This document contains detailed screenwriting guidance, including scene format standards, character description best practices and beat distribution recommendations.

---

## Scene Format Standards

### Standard Scene Heading

```markdown
## Scene {X} - {INT./EXT.} {Location} - {Time}

{Scene-establishing description - 2-3 visual sentences}

{Character action and dialogue}
```

**Example**:

```markdown
## Scene 5 - INT. Subway Car - Night

The car is dim, its white fluorescent lights flickering. A few discarded newspapers are scattered across the empty seats.

EMMA (25, long silver hair, deep red coat) sits by the window and opens an old leather notebook.
Dense handwritten symbols and a glowing hexagram pattern light up her face.

Suddenly, every light goes out.
```

### Scene Type Markers

- **INT.** = Interior
- **EXT.** = Exterior
- **INT./EXT.** = Includes both interior and exterior

### Time Markers

- Specific time: Morning, Noon, Afternoon, Dusk, Night, Late Night
- Relative time: Continuous, Later, Next Day

## Character First Appearance

**Must include**:

1. Name (if any)
2. Age range
3. Key appearance features (hair, clothing, signature items)

### Examples

```markdown
MARCUS (50s, short gray hair, navy blue suit with a red tie) pushes the door open and walks in.

LILY (teenage, around 16, short black hair with purple streaks, ripped jeans and a band T-shirt) leans against the wall.

THE STRANGER (gender unknown, cloaked entirely in black, face hidden behind a mask, only a silver cross necklace visible) stands in the shadows.
```

### Canonical Description

The appearance description established on first appearance must stay consistent in every later scene:

**First time**:

```
EMMA (25, long silver hair, deep red coat, violet eyes)
```

**Afterwards**:

```
Emma's long silver hair whips in the wind, her deep red coat wrapped tight around her.
Her violet eyes stare into the distance.
```

## Action Description Best Practices

### Use present tense, active voice

✅ **Correct**:

```
Emma rushes to the door. Her hand grabs the handle and shoves it open.
```

❌ **Wrong**:

```
Emma should run toward the door, and then she will open it.
```

### Visual first

❌ **Abstract description**:

```
Emma feels confused and afraid.
```

✅ **Visual description**:

```
Emma's eyes go wide, her fingers trembling as she turns the notebook's pages. A bead of sweat slides down her forehead.
She takes a step back, presses her back against the wall, breathing fast.
```

### Specific, not general

❌ **Vague**:

```
The room is a mess.
```

✅ **Specific**:

```
Books are scattered across the floor, a chair lies toppled, the curtains are half torn down. A coffee cup has tipped over on the desk, dark brown liquid spreading across the papers.
```

## Beat Distribution Guidance

### Distributing 9 beats across the three acts

Make sure the script contains **9 or more** clear key moments:

**Act One (Setup, ~25%)**:

- **Beat 1** (Opening): Establish the world and the protagonist's everyday life
- **Beat 2** (Inciting incident): An event that breaks the status quo
- **Beat 3** (Initial reaction): The protagonist's response to the inciting incident

**Act Two (Confrontation, ~50%)**:

- **Beat 4** (First attempt): The protagonist takes action
- **Beat 5** (Rising complication): Hits an obstacle or discovers new information
- **Beat 6** (Midpoint twist): A major turn that changes direction
- **Beat 7** (Low point): The biggest setback or moment of failure

**Act Three (Resolution, ~25%)**:

- **Beat 8** (Final confrontation / climax): Decisive action
- **Beat 9** (New equilibrium): The ending; a new normal is established

### Example: beat distribution for a 30-page script

| Beat   | Page | Type              | Example                                             |
| ------ | ---- | ----------------- | --------------------------------------------------- |
| Beat 1 | p.3  | Opening           | Protagonist at their everyday job                   |
| Beat 2 | p.7  | Inciting incident | Receives a mysterious package                       |
| Beat 3 | p.11 | Initial reaction  | Investigates where the package came from            |
| Beat 4 | p.15 | First attempt     | Finds the first clue                                |
| Beat 5 | p.19 | Complication      | Uncovers a deeper conspiracy                        |
| Beat 6 | p.23 | Midpoint twist    | Realizes the truth is not what they imagined        |
| Beat 7 | p.26 | Low point         | Betrayed, loses crucial information                 |
| Beat 8 | p.28 | Climax            | Final confrontation with the mastermind             |
| Beat 9 | p.30 | New equilibrium   | Problem solved, but a new setup is left for later   |

### Beat quality standards

Every beat should be:

- **Visual** - can be turned into a concrete image
- **Emotionally charged** - carries a clear emotional value
- **A narrative turning point** - pushes the story forward
- **Independently identifiable** - can be extracted as a standalone moment

## Series Continuity Management

### What to look for in previous episodes

**Analysis checklist**:

- [ ] Main characters and their development arcs
- [ ] Established world-building and rules
- [ ] Unresolved plot threads
- [ ] Changes in character relationships
- [ ] Visual style and tone
- [ ] Key scenes and locations already used

### First appearance vs. repeat appearance

**In episode one**:

```
EMMA (25, waist-length silver hair, pale porcelain skin, bright violet eyes, deep red coat) walks into the room.
```

**Episode two and later**:

```
Emma walks into the room, her long silver hair and deep red coat still striking in the dim light.
```

**Key point**: Keep the appearance keywords consistent, but there is no need to repeat the age and every detail each time.

### World-building consistency

**Established rules must be followed**:

If ep01 establishes that "magic fails during the day", ep02 cannot feature "a magic duel at high noon".

**Expand, but don't contradict**:

- ✅ ep02 introduces a new type of magic (expansion)
- ❌ ep02 changes an established rule of magic (contradiction)

## The Three-Act Structure in Detail

### Act One (Setup, ~25%)

**Goal**: Establish the world, introduce the characters, plant the seeds of conflict

**Elements**:

1. **Opening image** - visually establish the world
2. **Ordinary world** - show the protagonist's normal life
3. **Character introductions** - main characters appear
4. **Inciting incident** - breaks the status quo (usually at 10-15%)

**Example**:

```
Scenes 1-3: Emma's everyday work (librarian)
Scene 4: Discovers a hidden message in an ancient book (inciting incident)
Scene 5: Decides to investigate
```

### Act Two (Confrontation, ~50%)

**Goal**: The protagonist faces obstacles, conflict escalates, the plot gets more complicated

**Elements**:

1. **First attempt** - the protagonist takes action
2. **Rising action** - a series of obstacles and challenges
3. **Midpoint twist** (~50% mark) - a major discovery or reversal
4. **Low point** - the biggest failure or betrayal

**Example**:

```
Scenes 6-10: Follows clues, runs into a secret organization
Scene 11: Discovers the truth is more complicated than imagined (midpoint)
Scenes 12-14: Loses an ally, is hunted (low point)
```

### Act Three (Resolution, ~25%)

**Goal**: Resolve the conflict, reach the climax, establish a new equilibrium

**Elements**:

1. **Rallying** - the protagonist finds new strength or a new approach
2. **Final confrontation** - the climax scene
3. **Resolution** - the conflict is resolved
4. **New normal** - show the changed world and characters

**Example**:

```
Scene 15: Emma gains the key knowledge
Scenes 16-17: Final confrontation with the organization's leader (climax)
Scene 18: The crisis is resolved, but a hook is left for the sequel
```

## Dialogue Writing Techniques

### Consistent character voice

Every character should have a distinctive way of speaking:

**Marcus (50s, old-school gentleman)**:

```
"Young lady, this matter is far more complicated than you imagine. I suggest you think twice before you act."
```

**Lily (16, rebellious teen)**:

```
"Oh, come on, Marcus. Your antique rulebook doesn't work around here."
```

### Cut meaningless filler

❌ **Redundant**:

```
"Um, I think, maybe, perhaps, we should, you know, give it a try..."
```

✅ **Concise**:

```
"Let's try."
```

### Subtext

Don't say everything; give dialogue layers:

❌ **On the nose**:

```
"I don't trust you, because you betrayed me before."
```

✅ **Subtext**:

```
"You said that last time too." (implies distrust and a past betrayal)
```

## Output Checklist

After writing, check:

- [ ] Every scene has a clear scene heading (INT./EXT., location, time)
- [ ] Characters appearing for the first time have a full appearance description
- [ ] Action is written in present tense, active voice
- [ ] Contains at least 9 clear beats
- [ ] The three-act structure is complete
- [ ] Dialogue fits each character's personality
- [ ] Enough visual description; abstract psychological description avoided
- [ ] For a sequel, character appearance matches earlier episodes
- [ ] No contradictions in world-building
- [ ] No frontmatter metadata or template instructions
